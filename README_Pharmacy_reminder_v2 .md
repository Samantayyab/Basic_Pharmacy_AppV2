## Step 2: Multiple Medicine Reminders using Lists

In this version, the program allows the user to enter multiple medicines and corresponding dosage times, storing them in lists and printing a reminder for each one.

### Features:
Takes input for multiple medicines and timings

- Uses lists and for loop to manage reminders
Beginner-friendly and pharmacy-relevant use case


### Sample Output:
Reminder: Take Paracetamol in the morning.
Reminder: Take Amoxicillin in the night.s
